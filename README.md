Designed with inspiration from **21st.dev**, **threeui.com**, **tasteskill.dev**, and **gsap.com**.

---

## 🌟 Key Features

* **Cinematic Studio Hero Stage**: Seamless cyclorama video integration with directional overhead spotlight and liquid gold typography.
* **GSAP-Powered Magnetic Attraction**: Fluid cursor physics pulling buttons, pills, brand logos, and WhatsApp quick-connect towards the pointer.
* **21st.dev Orbiting Border Beam & Bento Grid**: Luminous perimeter lasers and dynamic cursor-following spotlight cards.
* **ThreeUI & Tasteskill.dev Interactive Terminal**: Multi-tab live telemetry cockpit (`telemetry.sh`, `yolo_pipeline.py`, `contact.json`) with one-click clipboard copying.
* **Interactive 3D Three.js Visualizations**:
  * Real-time 3D ambient particle wave field across the background.
  * Interactive 3D Holographic Earth Globe with Hyderabad geo-beacon and orbital laser arcs.
* **Full Mobile & Touch Optimization**: Native spring damping, responsive drawer navigation, and fluid 60 FPS touch tracking.

---

## 🛠️ Core AI/ML Engineering Projects

1. **Real-Time Object & Intrusion Detection (Computer Vision)**
   * Single-stage inference pipeline powered by YOLOv8, OpenCV, and PyTorch for multi-class bounding box classification and tracking.
2. **Toxic Span Extraction & Attention Classification (NLP)**
   * Token-level sequence classification using Transformer attention heads for granular content moderation.
3. **Librosa Audio Waveform & MFCC Music Genre Classifier (Audio ML)**
   * Acoustic spectral feature extraction converting audio waveforms into 13-band Mel-Frequency Cepstral Coefficients for neural classification.
4. **Conversational AI Chatbot with Buffer Memory (LLMs / LangChain)**
   * Context-aware conversational assistant with rolling memory buffer and interactive Streamlit UI.

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/67chandu/chandu-portfolio.git

# Navigate into directory
cd chandu-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Run Oxlint validation
npm run lint

# Production build
npm run build
```
